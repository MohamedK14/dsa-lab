Dynamic Array

  • In a real array, a removed slot isn't erased, just ignored. The old value stays in memory until something overwrites it.
  • When the array is full, it can't grow in place. A bigger one is allocated, everything is copied over, and the old one is freed.
  • Doubling the capacity keeps full copies rare, so push_back averages out to O(1).

A row of numbered slots. When it fills up, it grows.

Think of it like a classroom

An array is a classroom with a fixed number of desks in a row, each with a number. Students fill the desks one by one. When the room is full and another student arrives, you can't squeeze in a desk. You find a bigger room (usually twice the size), walk every student over to it, and give the old room back. That move is the resize you see when the capacity doubles.
